# Jim the Him

**[Play in your browser](https://jimmylovnjames.github.io/jim-the-him-builds/)** (phone or desktop, no install). Hold your phone sideways.

## Android

**[Download jim-the-him-v1.1.3.apk](https://github.com/jimmylovnjames/jim-the-him-builds/releases/download/v1.1.3/jim-the-him-v1.1.3.apk)** (82.6 MB)

- Android 7.0 or newer, 64-bit and 32-bit ARM phones.
- Eight stages, from Waimamaku Bush to the Graft Corp Fortress, with touch controls.

## Install

1. **Coming from v1.1.2?** Just install: it updates in place and keeps your save.
   **Coming from v1.1.1?** Uninstall it first (it used a different signing key, so Android says "App not installed").
2. Download the APK on the phone and open it from the download notification or the Files app, then tap **Install**.
   If Android asks, allow **Install unknown apps** for that app.
3. If Play Protect warns about an unknown developer, tap **More details**, then **Install anyway**.
